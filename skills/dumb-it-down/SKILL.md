# Dumb It Down

Use this skill only when the user explicitly calls it. Simplify the answer or explanation they are referring to; when no passage is specified, revise the most recent relevant assistant response.

Lead with the direct answer. Use familiar words, short sentences, and concrete examples only when they make the explanation easier to understand. Replace jargon with everyday language; explain an essential technical term briefly when it must stay.

Keep only what the user needs to understand the point or take the next step. Remove repetition, filler, unnecessary background, and elaborate formatting. Choose a short paragraph or a small list based on what is easiest to read.

Preserve the meaning, factual accuracy, essential instructions, and uncertainty. Match the user's level without talking down to them. Simplification should reduce reading effort while keeping enough information to be useful.

Return the simplified explanation directly, without a preamble about rewriting it. Apply this style to the current explanation and its follow-up clarifications until the user changes direction or requests more detail.
